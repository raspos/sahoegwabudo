## 정상

- 구조: 이야기는 `pipeline/stories_src/*.txt` 원고 → `pipeline/build_stories.py` → `public/data/stories/{asia,europe,africa,americas,oceania}.json`.
- 형식: 모든 이야기가 질문형 제목, 장면 3~4개, 출처(CIA World Factbook 항목 + 해당 나라 JSON 파일 주소, 확인일), 관련 나라, 관련 지표, 다음 탐험 추천을 가짐.
- 숫자: 인구·면적·비중·순위 같은 사회과부도 지표는 문장에 직접 쓰지 않고 토큰(`{{vr:KOR:density}}` 등)으로 적어 데이터 엔진에서 읽음. FAO 순위·수출 1위·최대 상대국·쾨펜 기후·지형 비율도 토큰.
- 자동 감사(`src/content/stories.test.ts`): 국가 수, 0편·2편 미만 국가, 주요 30개국 4편 미만, ID·제목 중복, 나라 이름·숫자를 지운 뒤 4글자 조각 유사도(0.45 초과 시 실패), 출처 누락, 잘못된 국가 코드·지표, 풀리지 않는 통계 토큰, 미완성 문구, 장면 수, 질문형 제목. 현재 모두 통과.
- 도감 UI: 분야 탭, 제목 먼저 보이고 눌러서 펼침, 간략 패널은 2편 + '이야기 n편 더', 함께 보기 나라 링크, 관련 세계 랭킹 링크, 다음 탐험, 출처 접기, '다 읽었어요'.
- 브라우저 점검(PC 1280px, 모바일 390px): AUT KOR JPN NOR BRA ETH BOL ISL MNG FJI LSO VAT — 모두 이야기 표시, '[자료 없음]' 없음, 가로 넘침 없음.
- 테스트 55개 통과, 빌드 통과.

## 실패·미검증

- 사실 확인 범위: 문장의 사실은 CIA World Factbook(2024~2025 미러)과 사회과부도 자료에서 가져왔고, 집필 중 잘린 문장은 원문 전체를 다시 열어 확인했음. 다만 452편을 사람이 한 편씩 다시 읽어 교차 검증하지는 않았음.
- Factbook 자체의 시점 차이: 일부 항목(언어·종교 비율 등)은 조사 연도가 오래됨(문장에 연도를 함께 적음).
- 기존 코드 이야기 17편은 이전 형식 그대로라 '다음 탐험'·함께 보기 링크가 없음(출처는 World Bank WDI로 표시).
- FAO 품목 영문명 일부가 원자료에서 글자가 깨져 있음(예: 마테 잎 `MatÃ© leaves`). 화면 표기는 한국어 이름이라 영향 없음.
